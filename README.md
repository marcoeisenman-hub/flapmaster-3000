# ⚡ FLAPMASTER 3000 ⚡

Un Flappy Bird synthwave hecho por **Marco**: esquiva tubos neón, desbloquea 12 skins y bate tu récord.

## Cómo jugar

| Acción | Teclado | Móvil |
| --- | --- | --- |
| Volar | `ESPACIO`, `↑` o `W` | Toca la pantalla |
| Pausa | `P` o `ESC` | Botón ❚❚ |
| Sonido | `M` | Botón 🔊 |
| Reintentar | `ESPACIO` o `ENTER` | Botón OTRA |

## Lo que tiene

- **12 skins** que se desbloquean pasando tubos en **una sola partida**: Classic, Alien (5), Fire (8), Robot (12), Ghost (16), Wizard (22), Unicorn (28), Dragon (36), Pizza (45), Galaxy (55), Ninja (65) y Rey Dorado (80).
- **6 zonas** que cambian cada 10 tubos: Noche Neón, Atardecer, Espacio Profundo, Aurora, Infierno e Hiperespacio.
- **Escudos**: orbes azules que a veces aparecen entre los tubos y te salvan de un golpe.
- **PERFECT**: pasa justo por el centro del hueco para hacer combos.
- **Tubos que se mueven** a partir de 12 puntos.
- **Medallas**: Bronce (10), Plata (20), Oro (30), Platino (50) y Leyenda (80).
- Récord, partidas, tubos totales y skins guardados por nombre en el navegador.
- Sonidos hechos con Web Audio, sin archivos.
- Funciona igual de rápido en pantallas de 60 Hz, 120 Hz o 144 Hz.

## Tecnología

Un solo archivo `index.html` con HTML, CSS y JavaScript (Canvas 2D). No necesita instalar nada: ábrelo en el navegador o publícalo en cualquier hosting estático, como Vercel.
